# ADR-001: Add GitLab as a format implementation

## Status

Accepted

## Context

GitLab Flavored Markdown differs from the GitHub output currently generated by gomarkdoc. In particular, GitLab source links use `/-/blob/`, and heading IDs collapse consecutive hyphens. GitLab.com and self-hosted instances use the same repository URL shape.

## Decision

Add a `GitLabFlavoredMarkdown` format selected by `--format gitlab`. Reuse the existing GitHub-compatible behavior where GitLab supports it, and override only GitLab-specific heading-link and source-link generation.

Use the detected or configured repository URL as the GitLab instance base. Do not add host detection or configuration.

Leave duplicate arbitrary documentation headings to GitLab's renderer, which assigns the documented `-1`, `-2`, and later suffixes. The formatter remains stateless; its generated `Constants` and `Variables` links are unique.

## Consequences

- GitLab.com and self-hosted GitLab repository links work with the existing repository metadata.
- The change adds no dependency or new configuration.
- Automatic format selection remains a future, separate feature.
